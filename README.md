# Learning C
This repository is a compilation of my journey learning C from the ground up.   
Everything here is written manually for me to build muscle memory.

I use the Dive into Systems book as my learning material linked here: https://diveintosystems.org/book/

* **Chapter 1: The Basics**
  * Variables, loops, and basic C syntax.
* **Chapter 2: Memory & Data Structures**
  * Pointers and direct memory manipulation.
  * Dynamic memory allocation (`malloc` and `free`).
  * Self-referential structs and Linked Lists.
  * File I/O (reading and writing to the hard drive).
